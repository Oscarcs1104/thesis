# Dependencies for the graph + SELFIES multimodal property predictor.
#
# --- Step 0: check which CUDA build your machine actually needs ---
#   nvidia-smi   # header shows the max CUDA the driver supports; pick a torch index <= that
#   Blackwell GPUs (RTX PRO 4000/4500/5000/6000, RTX 50-series): compute capability sm_120 ->
#     REQUIRES PyTorch >= 2.7 with a CUDA 12.8+ build. cu121/cu124 wheels have no sm_120 kernels
#     and fail with "no kernel image is available for execution on the device".
#   Indices: cu128, cu126, cu124, cu121, ... see https://pytorch.org/get-started/locally/
#   Prefer a venv/conda env you own (see README).
#
# --- Step 1: PyTorch + CUDA (install from the CUDA-specific index, not plain PyPI) ---
#   pip install torch --index-url https://download.pytorch.org/whl/cu128   # or the newest that fits
#
# --- Step 2: PyTorch Geometric ---
#   pip install torch-geometric
#   The graph encoder uses GCNConv/GATConv/GATv2Conv/GINEConv/global_mean_pool + to_dense_batch,
#   which work on PyG's native PyTorch fallback. The compiled extensions (torch_scatter,
#   torch_sparse, torch_cluster, torch_spline_conv) are optional, faster, and version-picky --
#   only bother with them if you hit an explicit error asking for one:
#     python -c "import torch; print(torch.__version__)"   # e.g. 2.6.0+cu121
#     pip install torch_scatter torch_sparse torch_cluster torch_spline_conv -f https://data.pyg.org/whl/torch-<that-version>.html
#
# --- Step 3: everything else in this file ---
#   pip install -r requirements.txt
